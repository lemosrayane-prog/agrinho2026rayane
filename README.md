# AgroBot 2026 - Robótica Agrícola Sustentável

![AgroBot](https://picsum.photos/id/1015/800/400)

**Projeto desenvolvido para o Agrinho 2026**  
**Categoria:** Desenvolvimento Front-End (Alura)

## 🎯 Sobre o Projeto

O **AgroBot 2026** é um site institucional que apresenta uma solução robótica inteligente para o agronegócio paranaense, com foco em **agricultura forte e sustentável**.

O projeto combina design moderno, boa experiência do usuário e conteúdo educativo sobre tecnologia no campo.

## ✨ Funcionalidades

- Design totalmente responsivo (funciona perfeitamente em celular e computador)
- Navegação suave entre seções
- Seção Hero impactante com imagem de fundo agrícola
- Pilares da Agricultura Sustentável
- Demonstração da solução robótica
- Métricas de impacto no Paraná
- Tecnologias utilizadas
- Seção de Conscientização

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Flexbox, Grid, animações e design responsivo
- **JavaScript** - Interatividade e scroll suave
- **Font Awesome** - Ícones profissionais
